## Typography (Max 4 sizes)

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Heading | 24px | 600 | 1.2 |
| Subheading | 18px | 600 | 1.3 |
| Body | 14px | 400 | 1.5 |
| Label / Table Header | 12px | 600 | 1.5 |

*Note: Table headers must use Weight 600 with `text-neutral-500` (uppercase) for clear hierarchy.*

## Color (Black, White, Grey Palette)

| Role | Value | Distribution | Usage |
|------|-------|--------------|-------|
| Surface (Dominant) | #ffffff | 60% | Main content area, cards |
| Background (Secondary) | #fafafa | 30% | Sidebar, App background |
| Border / Divider | #e5e5e5 | - | Structural separators, input borders |
| Text Primary | #171717 | - | Main headings, active nav items |
| Text Secondary | #737373 | - | Labels, muted text, table headers |
| Accent | #171717 | 10% | Primary CTA buttons, active links |
| Destructive | #dc2626 | - | Error text, destructive actions |

### Semantic Badge Colors
- **Status Badges:** Active: `bg-neutral-100 text-neutral-900` (Monochrome). Inactive: `bg-neutral-50 text-neutral-400`.
- **Role Badges:** Admin: `bg-neutral-900 text-white`. Member: `bg-neutral-100 text-neutral-900`.
- **Row Hover:** `hover:bg-neutral-50`.

---

## Mobile Responsiveness Contract

| Screen Size | Interaction Pattern | Accessibility |
|-------------|---------------------|---------------|
| Desktop (> 1024px) | Full Sidebar + Secondary Nav + Data Table | n/a |
| Tablet (768px - 1024px) | Collapsed Sidebar (Icons only) + Full Content | Tooltips or `aria-label` required for icons |
| Mobile (< 768px) | Hamburger Menu (Hidden Sidebar) + Card-based List Fallback | n/a |

**Table Fallback:** On mobile, tables must transform into a vertical stack of cards. Each card represents one row, with labels on the left and values on the right.

## Copywriting Contract

| Element | Copy |
|---------|------|
| Primary CTA | Save settings |
| Empty state heading | No audit logs found |
| Empty state body | Try adjusting your search filters or time range. |
| Error state | Unable to load audit logs. Please try again. |

---

## Specific Layout Contracts

### Audit Log Table (`/admin/system/audit`)
- **Desktop:** Columns: Actor, Action, Resource, Time. 16px cell padding.
- **Mobile:** Vertical card stack showing Actor & Action as primary, Resource & Time as secondary.

### Global Security Policies (`/admin/system/security`)
- **Layout:** Vertical form with 24px section spacing. 
- **Sticky Footer:** On all screens, the "Save settings" button must be pinned to the bottom of the viewport in a container with a subtle top border.
