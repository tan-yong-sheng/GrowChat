---

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | #ffffff | Background, surfaces |
| Secondary (30%) | #f3f4f6 | Cards, disabled input |
| Accent (10%) | #0066cc | Primary CTA buttons, links |
| Destructive | #dc2626 | Error text, destructive actions |

Accent reserved for: Primary CTA buttons ("Sign in", "Reset password", "Send reset link", "Verify email") and active links.

## Copywriting Contract

| Element | Copy |
|---------|------|
| Primary CTA | Verify email address, Reset password |
| Empty state heading | No pending verifications |
| Empty state body | Your email is already verified. You can sign in to your account. |
| Error state | This link is invalid or has expired. Please request a new one. |
| Destructive confirmation | Delete Account: Are you sure you want to permanently delete your account? |
