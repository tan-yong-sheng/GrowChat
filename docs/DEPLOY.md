# Deployment Guide

Complete guide to deploying GrowChat to Cloudflare Workers.

## TL;DR

```bash
git clone https://github.com/tan-yong-sheng/GrowChat.git
cd GrowChat
pnpm install
pnpm run setup          # ← Creates resources + sets secrets + deploys. Done.
```

After setup: register your account, then promote to admin:

```bash
pnpm exec wrangler d1 execute growchat --remote \
  --command="UPDATE users SET role='admin' WHERE email='YOUR_EMAIL'"
```

## `pnpm run setup` vs `pnpm run deploy`

These are **two different commands for two different purposes**:

|                  | `pnpm run setup`                                                                                  | `pnpm run deploy`                                                                                 |
| ---------------- | ------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------- |
| **When**         | First-time setup                                                                                  | After code changes                                                                                |
| **What it does** | Creates all Cloudflare resources (D1, R2, KV), applies migrations, sets secrets, **then deploys** | Builds CSS, runs the pre-deploy gate (lint → test → coverage → validate migrations), then deploys |
| **Interactive?** | Yes — walks you through each step                                                                 | No — automated CI/CD-style pipeline                                                               |
| **Run it**       | Once (or when onboarding a new environment)                                                       | Every time you change code                                                                        |

> **`pnpm run setup` includes deployment.** You do **not** need to run `pnpm run deploy` afterward. The wizard's final step deploys your app.

## One-Command Deploy (recommended)

### Interactive

```bash
git clone https://github.com/tan-yong-sheng/GrowChat.git
cd GrowChat
pnpm install
pnpm run setup
```

The wizard walks you through 5 steps:

1. **Create Cloudflare resources** — D1 database, R2 bucket, KV namespaces (skips if they already exist)
2. **Apply D1 migrations** — runs all migration files against the remote database
3. **Set secrets** — prompts for `JWT_SECRET` (auto-generated), `RESEND_API_KEY` (optional), `RESEND_FROM_EMAIL` (optional)
4. **Create admin account** — instructions for post-deploy promotion
5. **Deploy** — builds CSS and deploys to Cloudflare Workers

### With Environment Variables (CI/CD friendly)

The wizard detects pre-set environment variables and offers to use them instead of prompting:

```bash
export JWT_SECRET="your-secret-here"
export RESEND_API_KEY="re_xxxxx"
export RESEND_FROM_EMAIL="noreply@yourdomain.com"
pnpm run setup
```

When an env var is set, the wizard asks: _"Use the JWT_SECRET from environment? [Y/n]"_ — so you still have control, but no typing required.

### Fully Non-Interactive (advanced)

For CI/CD pipelines where you can't answer prompts, pipe defaults or use a wrapper script:

```bash
# Example: all secrets pre-set, wizard will auto-confirm env-var usage
JWT_SECRET="$(openssl rand -hex 32)" \
RESEND_API_KEY="re_xxxxx" \
RESEND_FROM_EMAIL="noreply@yourdomain.com" \
pnpm run setup
```

> **Note:** The wizard is inherently interactive (readline prompts). For fully headless deploys, use the [Manual Setup](#manual-setup-advanced) steps instead.

## Environment Variables Reference

### Secrets (stored in Cloudflare, never in files)

| Variable            | Required | How Set                                                   | Purpose                               |
| ------------------- | -------- | --------------------------------------------------------- | ------------------------------------- |
| `JWT_SECRET`        | ✅       | Auto-generated by wizard, or env var, or manual input     | Signs JWT access tokens (15-min TTL)  |
| `RESEND_API_KEY`    | ❌       | Env var, wizard prompt, or `wrangler secret put` later    | Transactional emails (password reset) |
| `RESEND_FROM_EMAIL` | ❌       | Env var, wizard prompt (default: `onboarding@resend.dev`) | Sender address for Resend emails      |

### Non-secret vars (in `wrangler.jsonc`)

| Variable          | Default                            | Purpose                                     |
| ----------------- | ---------------------------------- | ------------------------------------------- |
| `APP_NAME`        | `GrowChat`                         | App display name                            |
| `ENVIRONMENT`     | `production`                       | Environment identifier                      |
| `EMAIL_PROVIDER`  | `resend`                           | Email service provider                      |
| `ALLOWED_ORIGINS` | `https://REPLACE_WITH_YOUR_DOMAIN` | CORS allowed origins (update after deploy!) |

> **Important:** After first deploy, update `ALLOWED_ORIGINS` in `wrangler.jsonc` to your actual Workers URL, then re-deploy with `pnpm run deploy`.

```bash
cp template/.dev.vars.example .dev.vars
# Edit .dev.vars with your local values
```

## Post-Deploy: Create Admin

1. Open your Workers URL (shown in the wizard output or `wrangler deployments list`)
2. Register your account
3. Promote to admin:

```bash
pnpm exec wrangler d1 execute growchat --remote \
  --command="UPDATE users SET role='admin' WHERE email='YOUR_EMAIL'"
```

Or use the Cloudflare Dashboard → D1 → growchat → Console.

## Re-Deploying After Changes

After modifying code, deploy with the full pre-deploy gate:

```bash
pnpm run deploy
```

This runs: lint → format check → test → coverage → CSS build → validate migrations → `wrangler deploy`.

For faster deploys during development (skips the gate):

```bash
pnpm run build:css && pnpm exec wrangler deploy
```

## Local Development

```bash
pnpm run dev
```

Opens `http://localhost:8787`. Uses local D1 (`.wrangler/state/`) and local KV/R2 — no Cloudflare resources needed.

## Manual Setup (advanced)

If you prefer full control over each step, or need a headless deploy:

### 1. Create D1 Database

```bash
pnpm exec wrangler d1 create growchat
```

Copy the `database_id` from the output into `wrangler.jsonc` → `d1_databases[0].database_id`.

### 2. Create KV Namespaces

```bash
pnpm exec wrangler kv namespace create SESSIONS
pnpm exec wrangler kv namespace create CHAT_SESSIONS
pnpm exec wrangler kv namespace create CACHE
```

Update `wrangler.jsonc` with the namespace IDs.

### 3. Create R2 Bucket

```bash
pnpm exec wrangler r2 bucket create growchat-files
```

### 4. Apply D1 Migrations

```bash
pnpm exec wrangler d1 migrations apply growchat --remote
```

### 5. Set Secrets

```bash
pnpm exec wrangler secret put JWT_SECRET
pnpm exec wrangler secret put RESEND_API_KEY        # optional
pnpm exec wrangler secret put RESEND_FROM_EMAIL      # optional
```

### 6. Deploy

```bash
pnpm run deploy
```

## Cloudflare Resources Created

| Resource       | Binding         | Notes                                  |
| -------------- | --------------- | -------------------------------------- |
| D1 Database    | `DB`            | Primary data store                     |
| R2 Bucket      | `FILES`         | File uploads                           |
| KV Namespace   | `CHAT_SESSIONS` | Chat session state                     |
| KV Namespace   | `SESSIONS`      | Auth sessions                          |
| KV Namespace   | `CACHE`         | Application cache                      |
| Durable Object | `MESSAGE_QUEUE` | Auto-created on deploy — real-time SSE |

## Troubleshooting

### JWT_SECRET not configured

```bash
pnpm exec wrangler secret put JWT_SECRET
pnpm run deploy
```

### D1 Database errors

Check that `wrangler.jsonc` has the correct database ID:

```bash
pnpm exec wrangler d1 list
```

### Migrations out of sync

```bash
pnpm exec wrangler d1 migrations apply growchat --remote
```

### KV namespace errors

Verify namespace IDs match your account:

```bash
pnpm exec wrangler kv namespace list
```

### R2 bucket not found

```bash
pnpm exec wrangler r2 bucket create growchat-files
```

### ALLOWED_ORIGINS still set to placeholder

Edit `wrangler.jsonc` and replace `https://REPLACE_WITH_YOUR_DOMAIN` with your actual Workers URL, then:

```bash
pnpm run deploy
```
